# Hospitality Academy — Sales Demo Ready

Static GitHub Pages sales package. No backend, database, authentication, or real payment processing is included in this static demo.

## Pages
- `index.html` — main sales landing page
- `sales.html` — hotel sales/demo page
- `pricing.html` — pricing page
- `demo.html` — interactive visual platform demo
- `assets/style.css` — main stylesheet

## GitHub Pages
Upload the CONTENTS of this folder to the repository root (not the ZIP itself), then use Settings → Pages → Deploy from branch → `main` → `/ (root)`.

Expected URLs:
- `/hospitality-academy/`
- `/hospitality-academy/sales.html`
- `/hospitality-academy/pricing.html`
- `/hospitality-academy/demo.html`

## WhatsApp
The buttons currently open WhatsApp with a pre-written inquiry message. For a direct one-click business chat, replace the `https://wa.me/?text=...` links in the HTML files with your own WhatsApp click-to-chat URL.

## Important
All dashboard figures are explicitly labeled illustrative/fictional demo data and should not be presented as real hotel results.
